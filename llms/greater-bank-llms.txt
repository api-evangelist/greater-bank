# Greater Bank

> Greater Bank is a customer-owned Australian retail bank (part of Newcastle Greater Mutual Group / NGM Group) and a designated Consumer Data Right (CDR) data holder. Its only public API surface is the unauthenticated CDR Product Reference Data (PRD) API, which lists the bank's publicly offered products conforming to the DSB Consumer Data Standards.

## APIs

- [Greater Bank CDR Product Reference Data API](https://www.greater.com.au/openbanking): Public, unauthenticated PRD API at https://public.cdr.greater.com.au/cds-au/v1/banking/products. GET products list + product detail; requires the x-v version header (confirmed live at x-v 4, supported 4-5).
